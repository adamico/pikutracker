# Cart Import rebuilds what plays, not the stored SFX
_Partly superseded by [ADR 0022](0022-phrases-loop-as-sfx-do.md): Cart Import copies SFX loops into Phrase loops instead of unrolling them or using Fill. Partly superseded by [ADR 0023](0023-the-song-mirrors-the-carts-pattern-list.md): Cart Import brings in all of a Cart's music and claims every SFX it plays, not one chosen song's._

Cart Import works out how long PICO-8 plays each Pattern, in Ticks and by PICO-8's own rules, and turns each channel into a Phrase holding the Steps that channel plays in that time. An SFX does not map one-to-one to a Phrase. We chose this over copying each SFX into a Phrase because PICO-8's Pattern timing (the left-most non-looping channel ends the Pattern) differs from the Project's (the longest Phrase without a Phrase loop ends the Chain row, per ADR 0005 and [ADR 0022](0022-phrases-loop-as-sfx-do.md)). Copied SFX would make an imported Cart play differently in the tracker and after Export.

## Consequences

- A longer channel cut off by the left-most one gets a shortened Phrase. A Pattern that ends partway through a Step drops that Step.
- An SFX's loop start and end are copied into the Phrase loop, lead-in included, per [ADR 0022](0022-phrases-loop-as-sfx-do.md). The notes after a loop's end are kept, and the Phrase pane shows them dimmed. Nothing is unrolled, so nothing needs a warning.
- Import stays silent when it shortens a Phrase. That changes the stored data but not the sound, and Import warns only about results that sound different.
- LEN only cuts playback on the channel that sets the Pattern's length. On other channels, the notes after LEN are kept, because PICO-8 plays them.
- When every channel loops, PICO-8 plays 32 × the slowest Speed, so Import unrolls that channel into a plain 32-Step Phrase. A looping Phrase there would play its loop only once through ([ADR 0022](0022-phrases-loop-as-sfx-do.md)).
- SPD 0 becomes Speed 1, and the timing follows PICO-8's quirk. Import warns.
- A Cart's SFX can turn into several Phrases, so an Import → Export round trip may use different SFX slots.
- Import shares only Phrases that match exactly. It does not detect two SFX that play the same notes at different pitches, so every Chain transpose it writes is 0. Transpose detection is deliberately out of scope.
- Only the chosen song's SFX are claimed, and the SFX part of a Claim is a set of slots, not a range. A contiguous range would sweep in a game's sound effects lying between the song's instruments and its music, and Export would reset them. Every other non-empty SFX becomes a loose, unclaimed Phrase that keeps its loop.
- A LEN above 32 on the channel that sets the Pattern's length makes the Pattern run past the 32 Steps a Phrase can hold. Import splits that Pattern into several Chain rows of up to 32 Steps within one Song row. A looping channel starts each later Chain row with a Phrase that loops on from the note PICO-8 has reached. Other channels still sounding are unrolled into plain Phrases, and their Step that straddles a split is dropped with a warning. The timing stays exact only when each split lands on a Step boundary of every channel. A Phrase can't start partway through a Chain row, so when a split lands inside another channel's Step, that channel's later Steps play a few Ticks early. We accept this rather than change the model, and Import warns with the Pattern, the Track and how many Ticks early. The Claim does not grow by itself, so Import warns when the song no longer fits it, and Export fails until the user widens it.
- An SFX with bit 7 of byte 66 set that a Pattern plays directly becomes an ordinary Phrase of the Steps it plays, ignoring its LEN and loop. It never sets the Pattern's length, and Import warns.
- A Pattern holding only such SFX makes PICO-8 refuse to start or stall. Import keeps it as a 32-Step Chain row and warns, so the notes survive, and the Exported song plays through that point.
- The timing above started from zepto8 and fake-08. Real PICO-8 0.2.7 has since confirmed the rules for LEN and SPD 0 ([Check open PICO-8 behaviours against real PICO-8](https://github.com/adamico/pikutracker/issues/24)). It has also confirmed that a Pattern whose channels all loop plays 32 × the slowest Speed, and that an SFX with bit 7 of byte 66 set doesn't count towards that length ([Measure the last unchecked behaviours on real PICO-8](https://github.com/adamico/pikutracker/issues/29)).
