# Help hides while the Multitrack has focus

While the Multitrack has focus, Help is not drawn. It stays open, so it shows again as soon as focus returns to the Phrase, Chain or Song pane, and ToggleHelp still opens and closes it from the Multitrack. The Cart view and the Log keep their own lists, drawn over the Phrase and Chain/Song columns. The Multitrack is read only for now, so its list would be little more than Move, Undo and Redo. Covering the Phrase and Chain/Song panes to show that costs more than it gives. This narrows #99, which had Help follow every focus place.

## Consequences

- The Multitrack has no Help list. With Help open, focusing the Multitrack leaves the Phrase and Chain/Song panes as they are with Help closed.
- A Multitrack write mode would reopen this decision and give the Multitrack a Help list, drawn over the Phrase and Chain/Song columns like the Cart view's.
